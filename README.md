# Development Collection

Structured repository for organizing agents, skills, development tools, and prompts.

## Directory Structure

```
├── agents/           # AI agents and agent configurations
│   ├── templates/    # Agent templates and starter configs
│   └── docs/         # Agent documentation
├── skills/           # Installable skills and extensions
│   ├── templates/    # Skill templates
│   └── docs/         # Skill documentation
├── tools/            # Development tools, scripts, utilities
│   ├── templates/    # Tool templates
│   └── docs/         # Tool documentation
├── prompts/          # Prompt collections and templates
│   ├── templates/    # Prompt templates
│   └── docs/         # Prompt documentation
└── README.md         # This file
```

## Quick Start

1. **Adding Agents**: Place agent files/configs in `agents/`
2. **Adding Skills**: Place skill files in `skills/`
3. **Adding Tools**: Place tool scripts/configs in `tools/`
4. **Adding Prompts**: Place prompt files in `prompts/`

Use `templates/` subdirectories to organize reusable templates and `docs/` for documentation.
